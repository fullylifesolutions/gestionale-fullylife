Backup & Ripristino

💾

Esporta backup

Salva un file .json con i dati di questo emittente

Il file include le impostazioni fiscali, il catalogo personale e i documenti/fatture di questo emittente. Il catalogo comune e l'anagrafica clienti sono condivisi tra tutti gli emittenti e non entrano nel backup. Puoi scegliere una cartella specifica dove salvarlo automaticamente ad ogni backup.

📁 Cartella di backup
Nessuna cartella selezionata — verrà usata la cartella Download
⚠️ Il tuo browser non supporta la selezione diretta della cartella. Verrà usata la cartella Download standard.
💡 Consiglio: seleziona una cartella su iCloud Drive, Google Drive o Dropbox per avere i backup sincronizzati automaticamente.
📂

Ripristina backup

Carica un file .json salvato in precedenza

Il ripristino riempie l'emittente corrente con i dati del file (impostazioni fiscali, catalogo personale, documenti): pensato per un emittente vuoto appena creato — es. dopo aver ricreato l'ambiente da zero — non per unire dati in un emittente già in uso.

Nota: le impostazioni fiscali correnti di questo emittente verranno sovrascritte con quelle del backup. Catalogo e documenti vengono aggiunti (non sovrascritti) — un documento con un numero già esistente per questo emittente non verrà importato.
Clicca per selezionare un file .json di backup
